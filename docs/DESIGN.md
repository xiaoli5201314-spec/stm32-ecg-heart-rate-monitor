# 设计说明：信号处理核心与 PC 回环

本文说明当前源码的结构、公式与取舍，不将目标硬件参数写成已经完成的电路。默认配置来自 [ecg_config.h](../firmware/include/ecg_config.h)，当前运行证据见 [VERIFICATION.md](VERIFICATION.md)，复现方法见 [BUILD_AND_TEST.md](BUILD_AND_TEST.md)。

本仓库交付 C99 固件核心、PC HAL 桩和测试，目标为 STM32F103C8T6、250 Hz 单通道采样。**没有 PCB、STM32 板级驱动、启动/链接工程或 MFC GUI。**

## 1. 分层与可测试边界

| 层 | 实现 | 当前职责 |
|---|---|---|
| 算法/基础组件 | [ring_buffer.c](../firmware/src/ring_buffer.c)、[iir_notch.c](../firmware/src/iir_notch.c)、[savgol.c](../firmware/src/savgol.c)、[heart_rate.c](../firmware/src/heart_rate.c)、[frame_protocol.c](../firmware/src/frame_protocol.c) | 不直接操作 MCU 寄存器；独立状态与编解码 API |
| 流水线/设备集成 | [ecg_pipeline.c](../firmware/src/ecg_pipeline.c) | 标定换算、DSP 调用、DMA 回调、环形队列、报告与 UART 调度 |
| HAL | [hal.h](../firmware/include/hal.h)、[hal_stub.c](../firmware/hal/hal_stub.c) | 操作表、弱默认函数、回调分发；当前实现是 PC 模型 |

这样分层使硬件端口可以复用算法接口，但不意味着换 MCU 只填一张表就完成验收。还需要时钟/外设配置、回调上下文、内存序、缓冲所有权、错误恢复、链接和资源验证。当前操作表注册与分发实现也放在 PC 桩文件内，目标端口需要明确哪些通用部分可复用，不能直接把整个仿真文件链接进真机。

设备用静态 `s_dev` 绑定中断回调，仅支持一个已绑定实例。算法对象可分别初始化，但设备/HAL/CRC 全局状态不能由此推断为任意多实例并发安全。

## 2. 采样模型、单位和真实硬件缺口

### 2.1 PC 桩实际模拟的内容

```text
高斯 P/Q/R/S/T 分量
  + 50 Hz 正弦干扰 + 0.25 Hz 漂移 + 固定种子噪声
  -> 标称增益与 1.65 V 偏置
  -> 理想量化、ADC 饱和
  -> 循环 DMA 写入与半满/全满回调
  -> 主循环
  -> UART 字节存入主机内存
```

默认合成配置为 72 BPM、R 分量 1 mV、工频幅值 0.30 mV、漂移幅值 0.60 mV、噪声参数 0.030 mV。测试会改变心率、干扰开关和种子。这些是仿真输入定义，不是患者数据或“最坏临床场景”。

桩没有模拟电极阻抗、模拟高通/低通、RLD 共模反馈、真实 ADC 非线性、采样时钟误差、串口物理错误或电气安全。给模型增加干扰也不能保证它对真实硬件误差是保守上界。

### 2.2 配置中的模拟域参数

| 宏/参数 | 值 | 当前含义 |
|---|---|---|
| `ECG_AFE_GAIN_NOMINAL` | 1000 V/V | PC 标称增益及单位换算 |
| `ECG_AFE_REF_MV` | 1650 mV | PC 中点偏置 |
| `ECG_ADC_VREF_MV` / `ECG_ADC_BITS` | 3300 mV / 12 | 理想 ADC 模型与换算 |
| `ECG_AFE_HP_FIRST_HZ` | 0.05 Hz | 预期模拟级参数，未有电路/模型 |
| `ECG_AFE_HP_SECOND_HZ` | 0.5 Hz | 同上 |
| `ECG_AFE_LP_HZ` | 100 Hz | 预期抗混叠低通参数，未验证实际响应 |
| `ECG_AFE_RLD_HZ` | 150 Hz | 预期 RLD 参数，未实现/验证反馈回路 |

这些宏不能证明器件选型、前端保护、CMRR、基准精度或医疗电气安全。真实模拟前端必须在 ADC 前独立评估饱和与混叠，数字滤波无法补回已经饱和或混叠的数据。

### 2.3 单位契约

```text
ADC LSB = 3300 * 1000 / 4096 = 805.6640625 uV/count（ADC 输入侧）
标称电极比例 = ADC LSB / 1000 = 0.8056640625 uV/count
```

流水线换算：

```text
electrode_uv = (counts - intercept_counts) * electrode_uv_per_lsb
```

默认 `intercept_counts=0`、`valid=0`。因此第一步输出仍含电平搬移所对应的直流，不应把它称为已校准的交流心电。设备发波形前四舍五入并饱和到 `int16` 微伏；原始 counts、浮点微伏、协议整数微伏是三个不同的表示。

## 3. 采样时序与 DMA 分块

目标是由定时器触发 ADC，再由循环 DMA 接收，避免主循环调用间隔成为采样间隔。当前仓库验证的是其回调模型，不是实际硬件采样抖动。

```text
计划的 TIM2 时钟 = 72 MHz
PSC = 72e6 / (250 * 1000) - 1 = 287
ARR = 999
更新频率 = 72e6 / ((287+1)*(999+1)) = 250 Hz
```

真实端口需要核实定时器输入时钟、触发映射、ADC 转换时序和 DMA 模式，不能仅凭宏宣称采样“抖动为零”。更改采样率还需检查这些参数是否整除、积分窗和缓存等参数是否仍适用，不是只改一处就完成重新验收。

### DMA 与主循环的分工

```text
128 点 DMA 缓冲
  [0..63]   -> 半满回调 -> 采样环
  [64..127] -> 全满回调 -> 采样环
采样环 -> 主循环分批读取 -> 逐样本处理 -> 24 点波形块
```

启动顺序先挂回调、先启动 DMA、再启动定时器，以免首个转换无缓冲承接。回调不运行 DSP，而是调用泛型环形缓冲逐元素拷贝并记账。真机上必须在 DMA 再次覆盖相应半区之前完成安全搬运。

| 缓冲/批量 | 容量 | 可推算的量 |
|---|---|---|
| DMA 存储 | 128 × 2 B = 256 B | 半块 64/250 = 256 ms；整圈 512 ms |
| ADC 环 | 1024 × 2 B = 2048 B | 相当于 4.096 s 数据；容错取决于实际剩余空间 |
| TX 环 | 2048 × 1 B = 2048 B | 容量为字节，不能固定折算成某个带宽下的保证时间 |
| 主循环局部读取块 | 256 × 2 B = 512 B | 会反复读取至环空，不是每 tick 的硬上限 |
| 波形块 | 24 点 | 对应 96 ms 数据，主机看到的延迟还包括采样分块/队列/传输 |

停止不会刷新未满 DMA 半块或波形块。默认 60 s 集成输入共 15000 点，234 个完整半块交付 14976 点，末尾 24 点不触发回调。这是计数契约，不是已经证明整个输入无损。

## 4. SPSC 环形缓冲与内存序

[ring_buffer.c](../firmware/src/ring_buffer.c) 用运行时 `elem_size` 支持 `uint16` 采样环和 `uint8` 发送环，内部按元素 `memcpy`，避免强制类型转换造成对齐/别名问题。

- 容量必须是大于等于 2 的 2 次幂，槽位通过 `index & mask` 回绕。
- `head` 由生产者写，`tail` 由消费者写；无符号索引差区分空/满，不牺牲一个槽位。
- 生产者先复制数据，再 release 发布 `head`；消费者 acquire 读到 `head` 后再取数据，并发布 `tail`。
- 写入空间不足时只写可容纳部分，返回实际元素数；剩余元素计入 `overflow`。
- `reset()` 只有两端空闲时安全，运行中不能拿它代替同步。

| 分支 | 当前实现 | 能声称的边界 |
|---|---|---|
| GCC/Clang | `__atomic_*` acquire/release | Linux pthread 测试覆盖该分支 |
| 非 GNU | volatile 访问、当前为空的 `ECGRB_BARRIER()` | 不能声称有有效编译器屏障或 Keil/IAR 端口正确性 |

真机的中断、DMA、缓存/总线可见性仍需按目标平台分析。SPSC 不适用于多生产者或多消费者，也不能从 PC 线程测试推导实际中断 WCET。

慢消费者测试检查 `written + overflow == offered`、读取/剩余数量及顺序；Linux 双线程测试配置 400000 点。其线程创建失败路径可能跳过而整体不失败，验证应查看实际执行输出；2026-10-02 实际转移 400000 点的记录见 [VERIFICATION.md](VERIFICATION.md)。

## 5. 数字滤波设计

### 5.1 两级单极高通

[iir_notch.c](../firmware/src/iir_notch.c) 中高通使用：

```text
RC = 1/(2*pi*fc)
dt = 1/fs
a = RC/(RC+dt)
y[n] = a * (y[n-1] + x[n] - x[n-1])
```

默认 `fc=0.5 Hz`，两个相同单极节级联。这不等于“整体 -3 dB 截止恰为 0.5 Hz”的二阶 Butterworth 设计。

首样本将 `x[n-1]` 置为当前输入，输出 0，避免从零状态处理带偏置信号时形成巨大 DC 阶跃。QRS 导数也自举延迟线；学习期初段另外设有门控。这些措施针对启动污染，不保证所有上电/电极瞬态消失。

高通压低基线同时会改变慢分量、等电位线和峰高。比较“峰值保持”应先明确相对基线及测量对象，不能把高通移除 DC 的结果都归因于 SG 峰值衰减。代码使用 0.5 Hz 参数**不代表满足任何医疗标准**；改成 0.05 Hz 也不会自动变成诊断设备。

### 5.2 50 Hz 双二阶

实际系数生成公式为：

```text
w = 2*pi*f0/fs
alpha = sin(w)/(2*Q)
a0 = 1 + alpha
b0 = b2 = 1/a0
b1 = a1 = -2*cos(w)/a0
a2 = (1-alpha)/a0
H(z) = (b0 + b1*z^-1 + b2*z^-2) / (1 + a1*z^-1 + a2*z^-2)
```

默认 `fs=250 Hz, f0=50 Hz, Q=8`。源码系数测试的近似参考值为：

```text
b0 = b2 ≈ 0.9438940
b1 = a1 ≈ -0.5833586
a2 ≈ 0.8877879
```

上述是由公式得到的系数参考，不是硬件测试结果。零点位于单位圆的 `±w`；默认共轭极点模为 `sqrt(a2)<1`，但不能把极点角度也直接认作与零点相同。

两级相同节级联使总传递函数为 `H(z)^2`，dB 响应相加；同时也改变陷波邻近频率的幅度和相位。`Q` 是这套数字公式的参数，不能简单把 `f0/Q` 当作精确数字 -3 dB 带宽，或承诺与其他库中名为 `iirnotch` 的函数严格等价。

转置直接 II 型每节只保留两个递推状态：

```text
y  = b0*x + z1
z1 = b1*x - a1*y + z2
z2 = b2*x - a2*y
```

相比长 FIR，当前实现使用较小的状态与固定运算量，但没有通用的 FIR 阶数比较实验或 M3 微秒计时。IIR 群延迟随频率变化；理论零点/极低浮点残差不代表 ADC/模拟硬件具有同样动态范围。

当前测试用 12 s 正弦，跳过前 4 s，并检查 exact 50 Hz 和五个 49.5..50.5 Hz 离散探针。通带测试的现有聚合选择了衰减最小值，不能作为最大插损的验收，详见构建文档。

### 5.3 SG 核由最小二乘生成

默认阶数 `p=4`、奇数窗长 `L=17`，支持到 `p=6`、`L=41`，要求 `p<L`。中心位置 `m=(L-1)/2`，横坐标：

```text
x_i = (i-m)/m       （m=0 时取 0）
A[i][k] = x_i^k
e_pos = [1, x_pos, ..., x_pos^p]^T
```

窗口内拟合多项式后在输出点求值：

```text
min_c ||A*c-y||^2
c = (A^T*A)^-1*A^T*y
y_out = e_pos^T*c = h^T*y
```

实现不显式求整个逆矩阵，而求解：

```text
(A^T*A)*u = e_pos
h = A*u
```

`ecg_savgol_design_at()` 使用 double 的 Gauss-Jordan 消元和部分主元，之后归一化 `sum(h)`。横坐标归一到 `[-1,1]` 减小幂次跨度，但正规方程仍可能放大条件数，不等于对任意高阶参数稳定。当前阶数/窗长上限和测试是适用范围。

中心核在对称等权窗口中对称，可复现所拟合阶数内的多项式。测试包括 0 阶滑动平均、`[-3,12,17,12,-3]/35` 与 `[-2,3,6,7,6,3,-2]/21` 两个已知核、系数和/对称性、多项式和噪声增益。这些测试向量不证明实现的独创来源。

### 5.4 流式、边缘与延迟

| 接口 | 实际行为 |
|---|---|
| `ecg_savgol_apply()` | 内部用全窗；两端缩窗，点数不足阶数时直通 |
| `ecg_savgol_stream_push()` | 保存最近 L 点；未满窗直通，满窗后卷积 |

默认流式前 16 点直通，第 17 点开始输出 SG 结果。稳态中心核的线性相位延迟 `m/fs = 8/250 = 32 ms`，不是整条链的固定群延迟，也不是设备端到端延迟。启动、DMA 批量、QRS 包络等待与 UART 排队都要分别考虑。

流式和整段测试只在延迟对齐后的内部区间比较；不能宣称首尾也逐点一致。

### 5.5 参数扫描与度量

[test_sg_parameter_sweep()](../firmware/test/test_filters.c) 在 60 s、72 BPM、R 宽度参数 15 ms、30 uV 噪声的合成形态上遍历 39 个有效 `(阶数,窗长)` 组合，报告：

- `noise[dB]`：白噪声标准差增益为 `g=sqrt(sum(h²))`，表中降噪量为 `-20*log10(g)`；正值表示噪声减小。
- `peak_meas[%]`：该测试定义的滤波前后峰值比例。
- `distort[%]`：干净信号被滤波后的 RMS 差异，按 R 幅值归一。
- `error[%]`：滤波后含噪信号与干净真值的总 RMS 差异。

实现打印符合平均峰值保持约束的最低总误差组合；默认参数单独检查平均至少 95%、最差单搏至少 93%。没有断言默认参数就是打印出的最优组合，更不能推广成真实心电的全局最优。

对称中心平滑时，某偶数阶与后一奇数阶可能得到相同中心核，来自奇/偶基函数分离；这不适用于任意非中心输出或导数求值。加长窗可降低白噪声增益，但也改变窄峰，不应仅凭一个噪声指标选参数。

## 6. QRS 检测与 RR 统计

[heart_rate.c](../firmware/src/heart_rate.c) 使用增强斜率/包络的启发式检测链，不声称是诊断算法或完整标准算法的逐项复刻。

### 6.1 实际处理步骤

```text
d[n] = (2*x[n] + x[n-1] - x[n-3] - 2*x[n-4])/8
e[n] = d[n]^2
env[n] = 最近 37 点 e 的平均值
```

37/250 = 148 ms，为约 150 ms 积分窗口。首样本自举导数历史。初始 2 s 学习期忽略前约 250 ms 包络，然后以最大包络初始化信号/噪声估计；初始 RR 先验为 0.8 s / 75 BPM。

包络局部极大值是候选，不直接把每个超过阈值的样本都当一搏：

```text
spki = 0.125*peak + 0.875*spki
npki = 0.125*peak + 0.875*npki
threshold = npki + 0.25*(spki-npki)
threshold_back = 0.5*threshold
```

更新哪一项取决于候选接受/拒绝和噪声门控。噪声门控限定在 R 峰后 `min(360 ms, RR_median/2)`，避免 QRS 肩部/T 波系统性进入噪声估计。

### 6.2 候选筛选与峰值定位

- 200 ms 不应期拒绝过近包络峰。
- 360 ms 内较上一搏包络小于一半的候选使用 T 波启发式拒绝。
- 超过 `1.66*RR_median` 没有检测到心搏时，使用低阈值处理之后的新候选。**没有保存漏搏候选并回溯搜索**。
- 用 31 点历史缓冲向过去搜索绝对幅值最大的信号点，实际搜索滞后最多 30 点；不是前后对称 `±125 ms` 窗口。
- 按细化后的索引差计算 RR，接受范围 300..2000 ms。

算法输出的 `sample_index` 属于处理后信号的索引体系，不能直接当作未滤波生物电的无延迟时间。相同固定延迟在 RR 差分中会抵消，但形态变化、频率相关相位和离散定位仍可能带来误差。

### 6.3 中位数、异常值与 SQI

有效 RR 保存到 128 点序列，最近 5 个有效间期取中位数，`BPM = 60*fs/RR_median`。瞬时心率来自单个当前 RR，所谓平均报告实际是中位 RR 心率。

相对中位数偏差超过 40% 时，源码标记 `ECTOPIC`，不把该间期加入有效序列，但仍更新最近搏动位置。该规则必须等至少 3 个有效间期后才启用，否则 75 BPM 先验可能阻止不同节律收敛。它是 RR 异常剔除，不证明临床异位搏动诊断。

```text
SQI = round(100*spki/(spki+npki))，限制到 0..100
```

它不是概率、认证信号质量或诊断置信度。

HRV 接口提供均值、SDNN、RMSSD、pNN50 等字段，但当前 `sdnn_ms` 未乘 `1000/fs`，计算的是 RR 采样点的标准差。其他字段也需真实可变 RR 数据和参考实现复核；周期信号的接近零结果无法验证单位与临床意义。

## 7. 标定：拟合工具而非硬件流程

[ecg_cal_fit()](../firmware/src/ecg_pipeline.c) 对调用者提供的 2..8 个点拟合：

```text
counts = a*mv + b
a = (n*sum(x*y)-sum(x)*sum(y)) / (n*sum(x*x)-sum(x)^2)
b = (sum(y)-a*sum(x))/n
```

派生量：

```text
electrode_uv_per_lsb = 1000/a
afe_gain = a*ADC_LSB_UV/1000
nonlinearity_pct = 100*max(abs(y-fit))/(max(y)-min(y))
R2 = 1-SS_res/SS_tot
```

代码的非线性百分比按**所提供点的输出跨度**归一，不一定是 ADC 全量程。`ecg_cal_plateau_mean()` 对输入平台先做 3 点中值再取均值，测试验证孤立毛刺情形，不代表消除任意 ADC 错误。

现有测试从模拟高/低平台均值差构造峰峰值标定点，反推模拟模型的增益。差值会抵消平台共有偏置，所以拟合截距不能自动成为实际 ADC 零电极输入码；真实偏置校准、注入点、前端频响和安全隔离需另定义并验证。

`ecg_device_apply_calibration()` 接受拟合点并更新比例，不采集标定点、不保存到 Flash、不自动发标定报告。宏中方波/等待参数的存在也不代表自动标定状态机已完成。

## 8. 上行、错误处理与接收

完整字节规范见 [PROTOCOL.md](PROTOCOL.md)。主要设计取舍：

- 波形组帧前量化到整数微伏；PACK12 范围 `[-2048,2047]`，DELTA 可承接 int16 全范围。
- 每帧有 2 字节样本数；24 点 PACK12 的完整帧是 46 字节，不能忽略数量与 8 字节开销。
- DELTA 用 int16 基准、`[-127,127]` 差分、`0x80+int16` 绝对值转义；比较实际载荷长度，平局选 PACK12。
- 版本/类型、LEN、SEQ 和载荷受 CRC 校验；同步字靠接收器识别。CRC 不是安全认证。
- 自动上报波形/心率/状态，CAL/ACK 只有工具 API，NAK/HOST_CMD 只有枚举。

报告时钟来自 `processed/fs`，不是实际墙钟。心搏报告通常至少间隔 300 ms，状态在任务调用时检查距上次是否至少 5000 ms；主循环落后时不保证实际发送时间。

当前发送环写入可能只收下部分帧。UART 发送先从环移除最多 32 字节，再调用 HAL；即使 HAL 返回 0，该块也不会被放回或重试，短写只记丢失。这不是可靠背压设计，目标端口必须面对字节损失/坏帧与业务重传策略。

接收同步器每次拒绝滑动 1 字节，有界窗口跨调用保存半包；它没有坏长度等待超时，也不验证每种载荷的所有多余字节。批量接收函数在输出槽位用尽后仍消费输入，超出数组的帧会被丢弃。既定恢复测试不能推广为任意流/任意分片调用方式绝不丢帧。

## 9. 验证设计与结果解释

测试分三层：组件断言、合成信号的数值判据、PC 设备回环。默认主机测试的当前执行结果已列入 [VERIFICATION.md](VERIFICATION.md)；这里不复写旧测量表。

| 关注点 | 当前方法 | 仍缺的证据 |
|---|---|---|
| SG/陷波正确性 | 系数参考、频响与合成时域测试 | 真实波形、完整频带及单精度配置复核 |
| 心率 | 7 档干净、5 档含干扰合成记录；30 s 后稳态统计 | 公开真实数据库、标注 R 峰、漏检/误检分析 |
| 标定 | 多档模拟平台、拟合残差和毛刺用例 | 真标准源/ADC/前端误差、偏置及温漂 |
| SPSC | FIFO/容量记账与 Linux pthread 压力 | 目标中断、非 GNU 工具链、平台内存序 |
| 协议/集成 | 错帧/垃圾/分片与 60 s 虚拟回环 | 实串口、TX 背压、停止尾部、严格载荷验证 |
| 实时性/资源 | 缓冲字节数可由源码推算 | 目标链接 map、栈峰值、中断/单样本 WCET |

可选 NumPy 工具从 C 导出文件复算陷波系数，以 `pinv` 生成 SG 核，再复现整条流式链。SG 求解路径与 C 不同，陷波使用同一公式，不能称所有算法都由完全独立推导互相证明。缺文件时工具会回退，必须检查真实导出被加载。

2026-10-02 的 C 导出与 WSL / NumPy 1.21.5 复核已通过：系数最大差异 `4.645e-13`，全链路逐点最大差异 `5.060e-07 uV`。这证明所记录配置与输入下的数值复现，不证明真实硬件或临床有效性。

峰值保持分析必须分别说明：

1. 对象是 SG 单级还是整个链，是干净输入还是含干扰输入。
2. 比较的是绝对峰值还是相对局部等电位线的峰高。
3. 是否补偿延迟和采样栅格差异。
4. 是平均还是最差单搏，输入形态与参数是什么。

Python 工具包含延迟对齐、抛物线峰位和局部基线的分析。该次记录的 SG 单级平均/最差保持率为 98.39% / 98.38%，而全链路对干净参考的平均保持率为 89.74%，含干扰平均/最差为 88.64% / 81.39%。`distortion only` 的百分比仍是峰高保持率，不是“失真率 89.74%”；它隔离的是无外加干扰时全链路改变波形的影响。Python 的 PASS 只约束系数、逐点复现和 SG 平均保持率，不约束全链路峰高达到 95%。完整结果与方法见 [VERIFICATION.md](VERIFICATION.md)，不能提升为医疗形态保真结论。

## 10. 资源、移植与后续工作

仅 DMA/ADC 环/TX 环的存储可推算为 `256+2048+2048 = 4352 B`，不包括对象状态、SG 最大窗数组、求解矩阵、局部块和调用栈。SG 设计函数保留最大尺寸 Vandermonde/Gram 等 double 数组，初始化栈使用也要计入。

`ecg_real_t` 默认 double。启用 `ECG_USE_SINGLE_PRECISION` 会改部分存储/运算，但 SG 系数求解及卷积累加等仍有 double 工作，不能声称整体全切 float、资源全部减半或不再依赖数学库。目标 Cortex-M3 没有硬件 FPU，需要真正编译、链接和计时。

`make lib` 仅归档六个源文件，不含 HAL；`make arm` 将源文件编译输出到 `/dev/null`，既不链接也不保留固件镜像。两者都不能作为 Flash/RAM 合计或烧录成功的证据。

后续验收应至少包括：

1. 可构建的板级入口、HAL 通用部分与 STM32 外设端口、启动和链接工程。
2. 数据尾部刷新、整帧排队/背压、错误恢复与更严格协议输入校验。
3. 非恒定 RR 的单位测试，明确修复 SDNN 单位；修正通带最大插损统计后再建立判据。
4. 固定真实数据集、标注、参数与可复现漏检/误检评估，避免仅在合成形态上调参。
5. 目标 map/栈/最坏执行时间和实串口测量；如涉及人体输入，先完成独立的电气安全设计与验证。
