### 该 PASS 证明什么

- 当前默认 C99 主机配置的既定测试断言通过。

- 测试包含合成信号的滤波、心率、标定、协议及模拟 DMA/UART 回环。

### 该 PASS 不证明什么

- 没有证明 PCB、模拟前端、STM32 寄存器驱动、采样抖动、功耗、目标板实时性或电气安全。
- 没有真实患者/电极输入、临床数据库评估、医疗认证或诊断性能结论。
- 没有证明 SDNN 字段的毫秒单位正确，也没有证明现有通带测试给出的“最大插损”统计正确。限制见 [DESIGN.md](DESIGN.md)。
- 60 s 集成测试是虚拟采样过程；默认输入尾部未完成 DMA 半块的 24 点不计入交付数量。

### 数值结果与定义

| 指标 | 已记录结果 | 解释与范围 |
|---|---|---|
| 陷波/SG 系数最大绝对差异 | `4.645e-13` | C 导出系数与 NumPy 重算系数；脚本门限 `<1e-9` |
| 全链路 C 与 NumPy 逐点最大绝对差异 | `5.060e-07 uV` | 按 C 原始 ADC counts 复现流式输出；脚本门限 `<1e-4 uV` |
| 50 Hz 分量 RMS | 输入 `212.43 uV` → 输出 `0.0510 uV`，变化 `-72.4 dB` | 全链路输出的 50 Hz 单频投影，不是仅陷波级、连续频段或实板抑制深度 |
| SG 单级峰高保持率 | 平均 **98.39%**，最差 **98.38%** | 干净合成参考上的对齐中心核分析；脚本 PASS 要求平均 `>=95%` |
| 全链路，纯失真条件下的峰高保持率 | 平均 **89.74%** | 对干净参考执行完整链，隔离滤波本身的波形变化；不是“失真率 89.74%” |
| 全链路，含干扰时的峰高保持率 | 平均 **88.64%**，最差 **81.39%** | C 含工频、漂移与噪声的输出相对干净参考；不能用 SG 单级数字替代 |
| CSV 心搏通知推算心率 | 真值 `72 BPM` → `72.12 BPM`，绝对差 `0.12 BPM` | 根据 `beat` 通知索引的中位间期推算，不是逐搏报告误差或临床准确率 |

50 Hz 与峰高分析跳过前 2 s，并按脚本在 0..100 ms 范围内通过相关性选择的整数滞后对齐。峰高是抛物线峰值拟合减去 R 峰前 48..120 ms 的 PQ 段中位基线；SG 单级使用对齐的中心卷积。这里不补写未记录的实际最优滞后、参与统计搏数或干净全链路最差保持率。

### 如何解释 Python 的 PASS

该脚本的退出条件是：系数最大差异 `<1e-9`、完整链逐点差异 `<1e-4 uV`、SG 单级平均峰高保持率 `>=95%`。**它没有将全链路保持率、50 Hz 衰减或心率误差设为额外通过条件**；全链路平均保持率 89.74% 仍可与该 PASS 同时成立。

这些结果支持当前配置在所列合成记录上的数值一致性与取舍分析，不证明真实心电的形态保真、病理波形识别、医疗标准符合性或硬件性能。陷波复核使用相同公式，SG 使用 NumPy 伪逆而非 C 正规方程求解，不能说全部算法都经过完全独立的数学推导。

Python 目前没有减去导出的标定截距，打印的 `calibration` 差异也不是对 C 标定结果的独立比较；该次默认零截距 PASS 不能验证非零偏置标定。缺文件时脚本会回退，因此后续必须确认加载同一次 C 导出的三份文件，具体步骤见 [BUILD_AND_TEST.md](BUILD_AND_TEST.md)。
